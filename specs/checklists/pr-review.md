# Revisión de PR

- [ ] El PR referencia una feature (`F-NNN`) o es un hotfix justificado.
- [ ] El cambio coincide con `plan.md`; si se desvió, el plan se actualizó.
- [ ] Respeta la constitución (en especial PR-04, PR-05, PR-06, PR-09).
- [ ] No agrega dependencias no justificadas.
- [ ] Textos sin rayas ni guiones dobles, en voz y tono.
- [ ] Código generado por IA: lo entiendo y lo puedo explicar línea por línea.
- [ ] CI en verde.
