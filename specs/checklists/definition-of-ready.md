# Definition of Ready (DoR)

Una feature pasa a **Lista** cuando:

- [ ] `spec.md` completa: contexto, objetivo, alcance (incluye / no incluye).
- [ ] Trazada a requisitos `FR`/`NFR` existentes (o se agregaron a `requirements.md`).
- [ ] Criterios de aceptación verificables (Dado/Cuando/Entonces).
- [ ] Textos ES y EN definidos o con responsable.
- [ ] Wireframe o descripción de estados (vacío, error, móvil, oscuro) si tiene UI.
- [ ] Dependencias identificadas y resueltas o planificadas.
- [ ] Sin preguntas abiertas bloqueantes.
- [ ] Cabe en ≤ 2 semanas de trabajo nocturno; si no, se parte.
