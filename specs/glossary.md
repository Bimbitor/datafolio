# Glosario

| Término | Significado en este proyecto |
|---|---|
| Caso de estudio | Página de un proyecto con problema, arquitectura, decisiones, métricas y enlaces. Plantilla en `04-content/case-study-template.md`. |
| Proyecto insignia | El proyecto principal (propuesto: SkyPulse CO). Siempre a ≤ 2 clics. |
| Isla (island) | Componente Astro que sí envía JavaScript al navegador. Excepción, no regla (PR-04). |
| Content Collection | Carpeta de Markdown/MDX con esquema validado por Astro (Zod). Ver `02-architecture/content-model.md`. |
| Widget en vivo | Componente que muestra datos producidos por un pipeline real. Ver `02-architecture/data-pipeline.md`. |
| DoR / DoD | Definition of Ready / Definition of Done. Ver `checklists/`. |
| ADR | Architecture Decision Record. Registro inmutable de una decisión y su contexto. |
| `AI_USAGE.md` | Registro de qué hizo la IA, qué hizo Javi, qué se rechazó y cómo se verificó. |
| Bronze / Silver / Gold | Capas del lakehouse: crudo, limpio, modelado para consumo. |
